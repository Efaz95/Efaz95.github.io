# Efaz Khan - Portfolio

My personal portfolio website showcasing skills, projects, and professional experience.

## Features
- Modern, responsive design
- Dark theme with blue color palette
- Smooth animations and transitions
- Optimized performance
- Clean, organized codebase

## Technologies
- HTML5
- CSS3 (with custom variables)
- JavaScript (ES6+)
- Bootstrap 4
- Custom SVG favicons
- FontAwesome icons
- Google Fonts
